# UMS UI 原型说明

## 核心页面

### 1. 登录页（/login）
- 邮箱 + 密码输入框
- 「忘记密码」链接
- MFA 验证码输入框（MFA 开启后显示）
- 登录按钮 → 成功跳转到应用首页

### 2. OAuth2 授权页（/oauth2/authorize）
由 UMS 托管，用户已登录后显示：
- 应用名称 + Logo
- 请求的权限列表（scope 说明）
- 「允许」/「拒绝」按钮

### 3. 用户管理后台（/admin/users）
- 用户列表表格：搜索、状态过滤、分页
- 用户详情弹窗：基本信息 + 角色分配
- 操作列：启用/禁用/删除/重置密码

### 4. 个人设置页（/settings）
- 基本信息编辑（用户名、头像、手机）
- 修改密码表单
- MFA 开关（二维码展示 + 验证码确认）

## 页面跳转逻辑

```
未登录用户
  → 访问任意保护页面
  → 重定向到 /login
  → 登录成功 → 跳回原页面

OAuth2 三方应用
  → 引导用户到 /oauth2/authorize?client_id=...
  → 用户登录（如未登录）
  → 显示授权确认页
  → 用户确认 → 302 回调 redirect_uri?code=...
```
