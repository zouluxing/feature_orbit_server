## Step 3：用户验收测试（UAT）


**UAT 场景设计**（从用户角度，而非技术角度）：

```markdown
## UAT 场景一：新用户完整使用流程

**背景**：一个全新用户第一次使用系统

**步骤**：
1. 打开首页 → 看到注册入口（期望：入口明显）
2. 填写注册信息 → 提交（期望：成功注册，跳转引导页）
3. 验证邮箱 → 点击验证链接（期望：激活成功）
4. 首次登录 → 完成核心功能（期望：全流程顺畅）
5. 退出登录 → 再次登录（期望：状态正确恢复）

**验收结论**：✅ 通过 / ❌ 不通过（原因：）

## UAT 场景二：异常恢复场景

**步骤**：
1. 使用中断网络连接
2. 恢复网络后继续操作
3. 验证数据未丢失、状态正确
```
