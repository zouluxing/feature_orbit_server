## 分支策略

```
main          ←── 生产环境，仅通过 PR 合并，需打 Tag
  └── develop ←── 集成分支，各阶段 PR 合并目标
        ├── stage/requirements  需求阶段分支
        ├── stage/design        设计阶段分支
        ├── feature/xxx         功能开发分支（多个）
        ├── stage/testing       测试阶段分支
        ├── stage/qa            QA 阶段分支
        └── stage/deploy        部署阶段分支
```
