# UMS 测试计划

## 测试范围

| 层级 | 类型 | 目标覆盖率 |
|------|------|--------|
| Service 层 | 单元测试 | ≥ 80% |
| Handler 层 | 集成测试 | 核心路径全覆盖 |
| API 层 | E2E 冒烟测试 | P0 用户故事 |
| 安全专项 | 手工 + 自动化 | 100% |

## 安全专项

- SQL 注入: GORM 参数化查询
- JWT 算法混淆: 拒绝 none/HS256
- 密码存储: bcrypt cost=12
- MFA Secret: AES-256-GCM 加密
- Token 重放: refresh_token 轮换
- 登录限流: 5次失败锁定
- PKCE S256: 强制校验
